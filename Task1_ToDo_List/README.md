# Task 1 - To-Do List Application

## About the Project

This project is a console-based To-Do List application developed using Python as part of my CodSoft Python Programming Internship.

The application allows users to create and manage their daily tasks through a simple menu-driven interface.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Input validation
- Error handling
- Persistent task storage using JSON
- Tasks remain saved after closing and reopening the application

## Technologies Used

- Python
- JSON
- VS Code
- GitHub
