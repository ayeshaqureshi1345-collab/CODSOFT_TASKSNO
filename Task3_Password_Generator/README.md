# Password Generator

## Description

This is a simple Python Password Generator that creates a random password based on the length entered by the user.

The password can contain:

* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

## Features

* User can choose the password length.
* Generates a random password.
* Uses letters, numbers, and special characters.
* Checks for minimum password length.
* Handles invalid input.

## Technologies Used

* Python
* random module
* string module

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python password_generator.py
```

4. Enter the desired password length.

## Example

```text
===== PASSWORD GENERATOR =====
Enter the password length: 10
Generated Password: A7@kP2!xQ9
```

The generated password will be different each time because it is randomly created.
